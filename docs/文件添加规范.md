# Turtle 文件添加规范

> 本文件回答一个问题：**新增一个 Rhino 相关文件时，应该放到哪里？**
> 核心就一句话：**能嵌入的进 `Scripts/` 或 `Grasshopper/`，随插件分发的进 `Resources/`，只存档案的进 `assets/`。**

---

## 1. 三条去向，先分清

| 去向 | 含义 | 目录 | 安装后到哪 |
|---|---|---|---|
| **嵌入 .rhp** | 编译时打包进 Turtle.rhp，随插件一起走 | `Scripts/`（.py）、`Grasshopper/`（.ghuser） | 插件启动时解压/释放到本地 |
| **随插件分发** | 不嵌入，但和 .rhp 一起发布，用户拿到插件包就有 | `Resources/`（及其子目录） | 和 Turtle.rhp 放同一文件夹 |
| **只存档** | 不参与编译、不随插件分发，留底/备查 | `assets/` | 永远不进用户电脑 |

**判断口诀**：插件运行必须要用、且要跟着插件版本走 → 嵌入；用户要能自己拿到/替换/编辑 → 分发；只是原始素材或历史版本 → 存档。

---

## 2. 文件去向总表

| 文件类型 | 扩展名 | 放哪里 | 机制 | 备注 |
|---|---|---|---|---|
| Python 脚本 | `.py` | `Scripts/` | csproj 自动嵌入（`Scripts\**\*.py`） | 新脚本放进来自动嵌入，无需改工程 |
| GH 用户对象 | `.ghuser` | `Grasshopper/` | 嵌入 + 启动时释放到 GH 用户对象目录 | 需 SHA-256 校验自动覆盖旧版 |
| GH 组件源码 | `.cs` | `Grasshopper/` | 编译进 .rhp，GH 自动注册 | Category 统一用 `TurtleInfo.Category` |
| 工具栏 | `.rui` | `Resources/` | 随插件分发 | 与 .rhp 放同一文件夹 |
| 显示样式 | `.ini` | `Resources/DisplayStyles/` | 随插件分发 | 子目录按需建 |
| 材质文件 | `.rmtl` 等 | `Resources/Materials/` | 随插件分发 | 子目录按需建 |
| 其他独立资源（模板/别名等） | `.3dm` 等 | `Resources/<子目录>/` | 随插件分发 | 建对应的语义化子目录 |
| 原始素材 / 历史版本 | 任意 | `assets/<类型>/` | 只存档 | 不进 .rhp、不分发 |
| 工具脚本 | `.py` | `tools/` | 开发期工具 | 如 patch_ghuser.py |
| 命令源码 | `.cs` | `Commands/` | 编译进 .rhp | 每个命令一个文件 |

## 3. 各类文件详解

### 3.1 Python 脚本 → `Scripts/`

```text
// Scripts/ 目录（自动嵌入 .rhp）
Scripts/
├── BlockToSU.py      # 嵌入，安装后解压到 %APPDATA%\Turtle\Scripts
└── Outline.py
```

- **添加步骤**：把 `.py` 丢进 `Scripts/` 即自动嵌入，**不需要改 Turtle.csproj**（通配符 `Scripts\**\*.py` 已覆盖）。
- **调用**：C# 命令里 `Path.Combine(TurtlePlugin.ScriptDir, "xxx.py")` 拼路径，不要写绝对路径。
- **调试**：首次运行会解压到 `%APPDATA%\Turtle\Scripts`（Mac: `~/.config/Turtle/Scripts`），已存在则跳过——可以直接改缓存里的脚本，重启 Rhino 生效。
- **注意**：`assets/py/` 里的同名文件是原始存档，改动脚本时要同步，或直接以 `Scripts/` 为准、删掉 assets 里的旧版。

### 3.2 GH 用户对象 → `Grasshopper/`

```text
// Grasshopper/ 目录（.ghuser 嵌入 .rhp）
Grasshopper/
├── Arrows.ghuser              # 分发用（Category=Turtle），嵌入
├── TurtleInfo.cs              # 统一分类常量
└── TurtleHelloComponent.cs    # GHA 组件
```

- **添加步骤**：在 GH 里做好 cluster → `File > Create User Object` → 属性窗口 **Category 填 `Turtle`** → 保存进 `Grasshopper/`。
- **嵌入**：csproj 里显式写了 `<EmbeddedResource Include="Grasshopper\Arrows.ghuser" />`——**新增 ghuser 要在这行旁边补一条**（通配符只覆盖了 .py，ghuser 是逐条列出的）。
- **释放**：插件启动时把嵌入版本写到 `Grasshopper.Folders.DefaultUserObjectFolder`（Win: `%APPDATA%\Grasshopper\UserObjects`），SHA-256 校验不一致才覆盖。
- **炸开编辑**：ghuser 是 cluster，右键 Explode 可改内部参数，此特性保留。
- **改属性**：Category/SubCategory 可用 `tools/patch_ghuser.py` 批量改。

### 3.3 工具栏 → `Resources/`

```text
// Resources/ 目录（随插件分发，不嵌入）
Resources/
├── Turtle.rui              # 工具栏
├── DisplayStyles/          # ← ini 显示样式放这里
│   └── OutLine.ini
└── Materials/              # ← 材质放这里
    └── c-blue1.rmtl
```

- **分发方式**：`Turtle.rhp` 和 `Resources/` 整个文件夹一起发布；加载时 `_Toolbar` 打开 rui。
- **添加 ini/材质**：直接复制进对应子目录即可，无需改工程；子目录不存在就先建。
- **⚠️ 当前待办**：`assets/ini/`（5 个 .ini）和 `assets/materials/`（3 个 .rmtl）**还在存档里，未复制到 `Resources/` 对应子目录**——若要让它们随插件分发，需复制过去。

### 3.4 原始素材 / 历史版本 → `assets/`

```text
// assets/ 目录（只存档，不参与构建、不分发）
assets/
├── ghuser/arrows.ghuser   # 原始 ghuser（未 patch 版）
├── py/                     # 原始 py 存档
├── rui/Turtle.rui          # 旧工具栏存档
├── ini/                    # 显示样式原件
└── materials/              # 材质原件
```

- 这里的文件**永远不会**进 .rhp 或用户电脑，只用于留底、对比、重新制作。
- 改 ghuser 的原件放这里，patch 之后再覆盖到 `Grasshopper/` 分发。

### 3.5 新增 C# 命令 → `Commands/`

```text
// Commands/ 目录（编译进 .rhp）
Commands/
├── TurtleHello.cs
├── TurtleRun.cs            # 模板：复制改名即可
├── TurtleBlockToSu.cs
├── TurtleOutline.cs
└── TurtleClean.cs
```

- **添加步骤**：复制 `TurtleRun.cs` → 改类名 + `EnglishName` + 脚本名 → 重新编译 → 在 rui 里加按钮。

## 4. 添加文件速查（四步）

| 场景 | 放哪 | 改工程文件？ | 重启 |
|---|---|---|---|
| 加一个 .py 脚本 | `Scripts/` | 否（通配符已覆盖） | Rhino |
| 加一个 .ghuser | `Grasshopper/` | **是**（csproj 加一行 EmbeddedResource） | Rhino + GH |
| 加一个 .rui / ini / 材质 | `Resources/` 对应子目录 | 否 | Rhino |
| 加一个 C# 命令 | `Commands/`（复制模板） | 否 | Rhino |
| 存一份原始素材 | `assets/` 对应子目录 | 否 | — |

---

## 5. 分发时怎么打包

发布插件包 = `bin/Release/net7.0/Turtle.rhp` + `Resources/` 整个文件夹：

```text
// 发布包结构示例
Turtle/
├── Turtle.rhp              # 编译产物（含嵌入的 .py 和 .ghuser）
└── Resources/
    ├── Turtle.rui
    ├── DisplayStyles/
    └── Materials/
```

## 6. 常见错误

| 错误 | 原因 | 修正 |
|---|---|---|
| 加了 ghuser 但没出现在 GH 面板 | csproj 没加 EmbeddedResource 行 | 在 `<EmbeddedResource Include="Grasshopper\...` 旁补一条 |
| 用户拿到插件包但没有 rui/ini/材质 | 只发了 .rhp，忘了带 Resources/ | 把 Resources/ 整个目录一起发布 |
| 脚本在开发机正常、别人机器报错 | 脚本里写了绝对路径 | 改用 `TurtlePlugin.ScriptDir` 拼接 |
| 改了 ini 但用户电脑没生效 | ini 没随插件分发，或用户路径不对 | 确认在 Resources/ 下并随包发布 |
